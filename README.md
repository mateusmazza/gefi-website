# GEFI website mock-up

A static GitHub Pages concept for the Global Executive Function Initiative (GEFI).

## Pages

- Home: mission and main areas of work
- Resources: direct-assessment guidance, EFFORT, cultural survey, and readings
- Community: proposed governance structure and founding-member directory
- Participate: network membership, working groups, and activities

## Design direction

The mock-up combines the clean, colorful academic tone of the SPARK Lab MAGIC site with the scannable resource cards and direct pathways used by Item Response Warehouse and LEVANTE. It intentionally excludes Stanford logos and official Stanford wordmarks.

## Run locally

```bash
python3 -m http.server 8000
```

Then open <http://localhost:8000>.

## Content status

Public-facing content is adapted from the current GEFI website and the September 2026 structure proposal. Membership and working-group buttons remain inactive until the structure and launch timing are confirmed.
